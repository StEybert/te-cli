# Security Policy

Thank you for helping keep Tabular Editor CLI secure.

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in the Tabular Editor CLI, please **do not open a public GitHub issue or discussion**.

Instead, report the issue privately to:

**security@tabulareditor.com**

You can also visit our Trust Center for additional information about our security practices and compliance resources:

https://trust.tabulareditor.com/

When reporting a vulnerability, please include (if possible):

- Description of the issue
- Steps to reproduce
- Impact assessment
- Product and version affected
- Screenshots, logs, or proof of concept (if applicable)

## What to Expect

After receiving your report, we will:

- Acknowledge receipt of the report
- Investigate and validate the issue
- Work toward remediation where applicable
- Communicate status updates when appropriate

We appreciate responsible disclosure and ask that you do not publicly disclose security issues until remediation has been completed and communicated.

Thank you for helping improve the security of the Tabular Editor CLI.
